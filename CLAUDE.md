## Project Overview

Static HTML/CSS/JS website for **Brauu Agency** (agenciabrauu.com). All content is in **Spanish**. No build tools, no frameworks — plain files served via Cloudflare Pages.

## Deploy

- **Host:** Cloudflare Pages, connected to GitHub (auto-deploys on push to `main`)
- No build command needed — Cloudflare serves the static files directly
- Root of the repo is the site root

## File Structure Convention

```

├── blog/
│   ├── index.html      # Blog listing page
│   └── [slug]/

├── js/

```

## Blog Automation via n8n

The blog is populated automatically by n8n webhooks — do **not** hand-edit blog post files.

- n8n posts new articles by creating files in `blog/[slug]/index.html` and committing to the GitHub repo
- The blog listing page (`blog/index.html`) must read/render posts dynamically from a JSON manifest (`blog/posts.json`) that n8n also maintains
- `blog/posts.json` schema (each entry):
  ```json
  {
    "slug": "nombre-del-articulo",
    "title": "Título del artículo",
    "date": "2026-06-02",
    "excerpt": "Resumen breve...",
    "category": "automatización"
  }
  ```
- The blog listing page fetches `posts.json` via `fetch()` at runtime and renders the cards — no server-side rendering

## Key Constraints

- No npm, no bundler, no framework — keep it zero-dependency
- CSS and JS are vanilla; avoid jQuery or other libraries unless there is a strong reason
- All `<img>` tags must include `alt` attributes in Spanish
- Keep HTTP requests minimal — inline critical CSS if needed for Cloudflare performance
